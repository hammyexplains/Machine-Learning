# What is Machine Learning?

Machine Learning (ML) is a branch of Artificial Intelligence (AI) that enables computers to learn patterns from data and make predictions or decisions without being explicitly programmed for every scenario.

Instead of writing hundreds of rules, we provide data to the machine, and it learns the underlying patterns on its own.

## Why Do We Need Machine Learning?

Consider an email spam filter.

One approach is to manually write rules such as:

- If the email contains "Win Money", mark it as spam.
- If the email contains too many links, mark it as spam.

However, spammers constantly change their messages, making it difficult to maintain these rules.

With Machine Learning, we can provide thousands of examples of spam and non-spam emails. The model learns the patterns automatically and can identify new spam emails more effectively.

## How Machine Learning Works

### 1. Collect Data

The first step is gathering data relevant to the problem.

Example:

| Hours Studied | Result |
|--------------|---------|
| 2 | Fail |
| 4 | Pass |
| 6 | Pass |
| 1 | Fail |

### 2. Train the Model

A machine learning algorithm analyzes the data and learns relationships between inputs and outputs.

In this case, it may learn:

> More study hours generally increase the chances of passing.

### 3. Make Predictions

Once trained, the model can make predictions on unseen data.

For example:

- Hours Studied = 5
- Prediction = Pass

## Real-World Applications

### YouTube Recommendations
YouTube analyzes your watch history and viewing behavior to recommend videos you are likely to watch.

### Netflix Recommendations
Netflix suggests movies and shows based on your viewing preferences and similar users' interests.

### Gmail Spam Detection
Machine Learning helps Gmail identify spam emails automatically.

### Google Maps
Maps predicts traffic conditions and suggests the fastest routes using historical and real-time data.

### Online Shopping
Platforms like Amazon recommend products based on your browsing and purchase history.

## Key Idea

Machine Learning is not about memorizing data.

It is about learning patterns from existing data and using those patterns to make predictions on new data.

## Machine Learning in One Sentence

> Machine Learning is the process of teaching computers to learn from data and make predictions or decisions without being explicitly programmed for every situation.
